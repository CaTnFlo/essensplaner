# Local interface icons

`js/icons.js` contains a local SVG subset with a 24 px viewBox, stroke 2 and `currentColor`. No runtime library or network request is needed.

- Feather: calendar, clock, more-horizontal, star, shuffle, move, check, x, box. Source: https://github.com/feathericons/feather, MIT license in `LICENSE-feather.txt`.
- Lucide: pin, fish, bird, cooking-pot (`pot` in the local map). Source: https://github.com/lucide-icons/lucide/tree/main/icons, ISC license and inherited Feather notice in `LICENSE-lucide.txt`.

The original license texts were retrieved from the upstream repositories on 15 November 2026. Icons are decorative alongside visible labels or a named button. The cooking-pot glyph accompanies the explicit Airfryer label; it does not imply another appliance filter.
